프로젝트 개요

CCPP EPC 프로젝트의 MDL(Master Document List)을 자동 생성하는 시스템입니다.

버전 0.1.0 언어 Python 3.11+ 브랜치 phase2-initial 패키지 uv API FastAPI :8000

두산에너빌리티 CCPP(복합화력발전소) EPC 프로젝트에서, 입찰 시 고객이 제공하는 ITB(Invitation To Bid) 문서를 분석하고, 과거 프로젝트의 MDL(Master Document List)과 매칭하여 필요한 기술 문서 목록과 제출 일정(FA/FC 날짜)을 자동으로 생성합니다.

입력 1 — ITB

고객 PDF. 설비·시공·시운전 요구사항 포함. 어떤 문서를 제출해야 하는지는 직접 명시하지 않음.

입력 2 — MDL

과거 CCPP 프로젝트(Fadhili, Grati, Karabatan 등)의 Excel 문서 목록. Neo4j에 임베딩 저장.

입력 3 — CCPP Guide Schedule

두산 표준 일정 참조 데이터. 4,039개 활동(activity) 포함. FA/FC 날짜 계산의 기준.

출력

문서별 FA(First Approval) / FC(Final Comment) 제출 일정 JSON·XLSX. ITB 출처 추적(itb_sources) 포함.

핵심 워크플로

ITB PDF → 파싱/청킹 → LLM 추출 → ITB↔MDL 매칭 ↓ /schedule/candidates (MDL 후보 추출) ↓ /schedule/generate (FA/FC 일정 생성)
