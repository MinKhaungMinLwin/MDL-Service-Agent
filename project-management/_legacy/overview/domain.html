프로젝트에서 사용되는 핵심 용어와 약어를 정리합니다.

용어설명
ITBInvitation To Bid — 고객 요구사항 PDF
MDLMaster Document List — EPC 계약자가 납품해야 하는 기술 문서 목록
CCPPCombined Cycle Power Plant — 복합화력발전소 (가스터빈 + HRSG + 증기터빈)
FAFirst Approval — 최초 제출일
FCFinal Comment — 검토 후 최종 제출일
FIFor Information — 승인 불필요, 정보 제공용
CCPP Guide Schedule두산 표준 참조 일정 (4,039개 활동)
Validation RuleMDL 문서 유형 → FA/FI/SKIP + VT 공식 매핑 규칙
VT Formula날짜 오프셋 공식 (예: start+4W<=FA<=start+6W)
NTP DateNotice to Proceed — 실제 프로젝트 착공 기준일. 템플릿 날짜를 실제 달력으로 이동
