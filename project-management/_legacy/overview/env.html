환경 변수

.env.example을 복사해 .env를 만들고 값을 채웁니다.

Azure OpenAI

변수설명예시
AZURE_OPENAI_ENDPOINTAzure OpenAI 엔드포인트https://....openai.azure.com/
AZURE_OPENAI_API_KEYAPI 키—
AZURE_OPENAI_CHAT_DEPLOYMENT채팅 모델 배포명gpt-5.2
AZURE_OPENAI_CHAT_API_VERSIONChat API 버전2024-12-01-preview

임베딩

변수설명예시
EMBEDDING_MODEL임베딩 모델text-embedding-3-large
EMBEDDING_DIMENSIONS임베딩 차원1536
EMBEDDING_BATCH_SIZE배치 크기2048
AZURE_OPENAI_EMBEDDING_API_VERSIONEmbedding API 버전2024-02-01

Neo4j

변수설명예시
NEO4J_URI연결 URIbolt://localhost:7687
NEO4J_USER사용자neo4j
NEO4J_PASSWORD비밀번호—
NEO4J_DATABASE데이터베이스neo4j
NEO4J_MAX_POOL_SIZE커넥션 풀 크기50

설정 방법

cp .env.example .env
# .env 파일을 열어 API 키, Neo4j 비밀번호 등 입력
/schedule/generate는 시맨틱 매칭이 필수이므로 Azure OpenAI 자격증명이 반드시 필요합니다.
