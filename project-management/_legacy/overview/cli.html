CLI 명령어

저장소 루트에서 uv run <command>으로 실행합니다.

MDL / ITB 처리

명령어설명
mdl-classifyMDL Excel → LLM 분류 CSV
mdl-ingest분류된 MDL CSV → Neo4j 적재
mdl-export-catalogMDL 카탈로그보내기
itb-extractITB 청크 → Depth/Keywords LLM 추출
itb-matchITB↔MDL 매칭 (keyword / semantic / hybrid)

평가 / 실험

명령어설명
itb-eval-build-ground-truth매칭 Ground Truth 생성 (LLM 검증)
itb-eval-matching매칭 품질 평가
schedule-eval일정 생성 품질 평가
acc-*ACC(정확도) 실험 관련 명령어 모음

사용 예시

uv run mdl-classify
uv run mdl-ingest
uv run itb-extract --section 7
uv run itb-match --retrieval-mode hybrid
uv run itb-match --retrieval-mode hybrid --source-file R&N_MDL.xlsx
