서비스 모듈

src/ 하위의 주요 Python 모듈과 역할입니다.

모듈경로역할
api src/api/ FastAPI 진입점. health, parser, chunker, schedule 라우트 제공
mdl_service src/mdl_service/ MDL Excel LLM 분류(mdl-classify), Neo4j 적재(mdl-ingest)
itb_service src/itb_service/ ITB 청크에서 Depth/Keywords/Search Query LLM 추출(itb-extract)
matching_service src/matching_service/ ITB↔MDL 벡터 검색 + Cross-encoder 재순위(itb-match). keyword/semantic/hybrid 모드
schedule_service src/schedule_service/ MDL 후보 추출(candidates) + FA/FC 일정 생성(generate). Rule/Activity 매칭 핵심
evaluation_service src/evaluation_service/ 매칭·일정 품질 평가, Ground Truth 생성, ACC 실험
parser_service src/parser_service/ PDF 파싱 (Docling 기반)
chunker_service src/chunker_service/ 파싱된 문서를 계층적 청크로 분할
common src/common/ Neo4j 클라이언트, OpenAI/Embedding 클라이언트, 설정, 텍스트 정규화 공통 유틸
