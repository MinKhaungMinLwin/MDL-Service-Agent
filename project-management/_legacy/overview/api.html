API 엔드포인트

FastAPI 기반 REST API. 기본 포트 8000.

메서드경로설명
GET /health 서비스 헬스 체크
POST /parser/... PDF 업로드 및 파싱
POST /chunker/... 파싱 결과를 청크로 분할
POST /schedule/candidates ITB 매칭 결과 → MDL 문서 후보 목록 생성. classify_with_llm 옵션 지원
POST /schedule/generate MDL 문서 → FA/FC 날짜 생성. ntp_date, rule_csv 옵션. 시맨틱 매칭 필수(Azure 자격증명 필요)
/schedule/map 엔드포인트는 feat/mia-2 리팩터링에서 제거됨. Activity 조회는 이제 /schedule/generate 내부에서 처리.

/schedule/candidates

output_match_*.csv를 입력으로, ITB 청크별 Matched_Doc_1..N(점수 ≥ 0.75)을 파싱하여 MDL 후보 목록을 생성합니다.

curl -X POST "http://localhost:8000/schedule/candidates" \
  --get --data-urlencode "input_csv=output/current_test_env/matching/hybrid/output_match_all_projects_section6.csv"

/schedule/generate

mdl_candidates_*.csv 또는 *_MDL_classified.csv를 입력으로 FA/FC 일정을 생성합니다.

curl -X POST "http://localhost:8000/schedule/generate" \
  --get \
  --data-urlencode "input_csv=output/schedule_service/candidates/mdl_candidates_....csv" \
  --data-urlencode "ntp_date=2024-03-01"
